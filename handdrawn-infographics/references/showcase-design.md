# GitHub 展示说明

2026-09-27。此说明记录公开介绍与示例图片的编排依据，不改变绘图功能。

## 页面组织

先看大幅真实示例，再看单张图与使用方法。首屏主图使用现有生成器产出的树形 SVG；窄屏主图独立排版，采用内容较少的文章版树形图。两张都保留原始矢量线条和可编辑文字，PNG 从 SVG 直接导出。

九图总览用于快速辨认构图，分组示例页以单张全宽图片展示实际内容。每张提供书籍版与文章版 SVG／PNG。文章版允许按阅读需要调整示例内容和结构密度，因此不将其描述为书籍版的机械缩小。

只更新本 Skill 的 README、示例资源及集合首页的对应入口。仓库包含其他独立 Skill，因此不替换整个仓库的社交分享图、品牌定位，也不增加本任务无关的账号设置、徽章或社区流程。

| [Mermaid](https://github.com/mermaid-js/mermaid) | 先说明用途，提供编辑器、文档与入门入口，按图形类型组织示例；有中文入口及贡献、安全说明 | 先给查看与使用入口，按信息关系组织示例，并区分支持范围与扩展方向 | 不添加本 Skill 尚不存在的在线编辑器或服务能力 |
| [Excalidraw](https://github.com/excalidraw/excalidraw) | 编辑器与文档入口靠前，简短定位后列出功能；贡献与许可链接明确 | 让真实手绘效果先出现，再解释能力、使用和导出方式 | 不把白板协作、在线存储等其他产品能力写进本 Skill |

本次不新增徽章：14 种结构与 20 类选型在正文解释即可。默认文档保留中文，与现有仓库读者一致；没有增加尚未维护的翻译入口。

## 图片与维护

- 主图：`assets/showcase/SVG/` 为母版，`assets/showcase/PNG/` 为网页图片；窄屏通过 README 的 `picture` 选择独立主图。
- 单张示例：`assets/examples/SVG/` 与 `assets/examples/PNG/` 同名对应；书籍版输入为 `structures.json`，文章版输入为 `articles.json`。
- PNG 用于直接查看，SVG 用于编辑。默认小赖字体与 OFL 许可随仓库分发，SVG 内嵌当前用字。换字体或改长文本后重新测量和看图。
- 主图与示例均使用公开的原创演示文案，不包含私人书稿、个人路径或聊天内容。
- 验收包含真实 GitHub 页面、窄屏呈现、图片加载与链接；本说明中的设计选择本身不作为验收通过的证据。
