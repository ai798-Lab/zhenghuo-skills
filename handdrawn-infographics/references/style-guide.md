# B 方案：视觉与阅读规范

## 视觉来源

用户于 2026-09-27 确认图书重绘配图 B 方案，并要求后续文章与内容制作默认沿用。两张本地样图是风格锚点；无需复制原书稿与全书内容。图标来自 DSH 使用的 sketchyicons 几何，许可见 `assets/NOTICE-sketchyicons.txt`。

## 配色

| 用途 | 色值 |
| --- | --- |
| 画布 | `#FFFFFF` |
| 主标题 / 线条 | `#1B1C18` |
| 正文 | `#32352E` |
| 荧光绿高亮 | `#D5F548` |
| 紫色强调 | `#B591EF` |
| 浅橙强调、人工确认 | `#FFC5A4` |
| 青绿强调 | `#9DDDD0` |
| 卡片淡色组 | `#F0F8CF` / `#ECE2FC` / `#DCF3EB` / `#EEE5FC` / `#FFE9DC` / `#EBF6CB` |

饱和色用于小块高亮；正文底色要浅。人工审核可用浅橙，但必须同时有文字标签。不要只靠颜色表达状态。

## 线稿

- 960 单位画布上约 2.5–3.6 单位黑线，圆端点和连接，偏移有控制，不加噪点滤镜。
- 图标是真实矢量路径，笔画轻微弯曲和漂移。附 copy、messages-square、search、book-open、puzzle、chart-line、timeline、download、rocket、external-link；生成器另有 folder、checklist。
- 卡片略弯但边界清楚，仅在卡片布局中使用拼图凸口/凹口。树的连线、判断菱形、集合圆、矩阵坐标、泳道与表格都沿用相同配色、字体和线条，不额外包一层拼图卡片。标题高亮与右上拼图图标用于保持同组辨识度。
- 箭头服从真实关系、避让文字；数据轴线、刻度、面积、点位保持准确，手绘只作用于外框与注释。
- 正文图标与线条是风格的一部分，不能只保留标题旁的拼图装饰。直接复用附带的 sketchyicons 几何或原有 folder / checklist 自定义路径；不要替换成标准几何图标、emoji 或光滑图标字体。
- 新结构中的节点、层级标签、集合区域和比较表头应有与内容相关的图标。无需给每个数据点和表格单元格都加装饰。宽节点图标可放在标题右侧，窄节点放在标题上方；字号和正文宽度优先，不以缩字换空间。
- 普通连接与多边形边框通过固定端点、有限曲率形成自然笔触，避免无规则抖动。坐标轴保持笔直；手绘效果不改变方向、数值、归属或交集。验收同时看内容关系与原版的图标/笔触，不能以配色相同代替风格一致。

## 字体和尺寸

首选 HarmonyOS Sans SC Regular / Bold。不用手写体或波浪扭曲。字体名称写入 SVG；全部文字是独立 `<text>`。

| 模式 | 960 单位设计画布 | 实际阅读目标 |
| --- | --- | --- |
| 书籍 book | 标题 44，卡片标题 32，正文 26，辅助 24 | 宽 144 mm 时正文约 11.1 pt，辅助约 10.2 pt |
| 文章 article | 标题 52，节点标题 42，正文 38，辅助 34 | 360 px 宽时正文约 14.25 px，辅助约 12.75 px；长文步骤单列，关系图保留其结构 |

相对字号取决于显示宽度。600 dpi 改善清晰度，不能把字变大。更窄版心应重新核算，低于 10 pt 要重排。重要结论不要放辅助小字。文章默认 PNG 宽 1440 px；书籍宽 144 mm、600 dpi（约 3402 px）。不要为统一图高压缩内容；长图可拆分，拆后关系仍须清楚。

## 布局

- 先使用 [结构选型库](structure-library.md) 决定信息关系。下面是阅读适配提醒，不是只能选这些形式。
- 并列知识点：只有确为独立条目时使用卡片，手机可单列；中心主题、分类和二维定位分别考虑辐射、树与矩阵。
- 4–8 步流程：书籍两列多行，手机单列。需严格表现每条连接时用纵向或专门折线。
- 闭环：4 / 6 节点可顺时针围排；其他节点数或手机图用纵向加返回线。返回必须有内容依据。
- 对比：维度对应优先对照表或小多图；手机仍保留“同一维度比较两方”，而非先读完 A 再回忆 B。
- 时间轴：写明真实日期/阶段，单方向排列，不造日期。
- 分支/并行：显式分叉汇合，不套串行模板。
- 结构树：父子连线与缩进；目录对比不用算法箭头。
- 数据图：准确坐标、单位、来源、刻度，不用失真图形暗示数量。

树、矩阵、集合和泳道不受“一行只能两个信息块”的笼统限制。文字密度与阅读尺度才是边界。必要时用总览图加局部说明，不能为了适配手机抹掉原有关系。

同组配图统一字体、颜色、边距和装饰密度。图号只在场景需要时添加。处理顺序：确认关系 → 测量字体 → 断行 → 加空间 → 必要时拆图。中文标点不放行首，英文单词和短文件名尽量不拆；超长标识符必须断行时保留全部字符并核对。不能以缩字或删限制条件解决拥挤。

自动折行不是中文语义分词。尤其判断菱形、窄树节点和交集区域，作者应先安排短语边界。字段内可用 `\n` 显式换行，例如 `稿件\n关键事实\n已核实吗？`，避免把“事实”“核实”拆到两行。显式换行后仍须按最终宽度看图；单行太长时仍会折行，不代表自动通过。
